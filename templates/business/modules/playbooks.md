# Playbooks & SOPs

> A business module is a system that makes the company repeatable. This one is an example
> — the standard operating procedures an operator or agent follows to produce consistent
> output. It's set to `scoped` so only named internal agents can read it; edit the
> `scope` list or delete this file. Add other modules (CRM, finances, operations, goals,
> brand-templates, tech-stack) the same way.

## How to use this module
An SOP written clearly enough for a new hire is most of the way to being a protocol an
agent can execute. Write each one as numbered, unambiguous steps.

## Playbook: [name]
**Purpose:** what this produces and when to run it.
**Owner:** who's accountable.
**Steps:**
1. …
2. …
3. …
**Definition of done:** how you know it's complete and correct.
