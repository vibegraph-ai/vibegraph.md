# Modules — Knowledge Base (Business)

Each file here is a **module**: a system that runs the business, structured so a
teammate, contractor, or agent can produce consistent output. `playbooks.md` is an
example to copy or delete.

**Suggested business modules:** Relationships (CRM) · Finances · Operations ·
Skills (Playbooks/SOPs) · Management · Brand Templates · Goals · Notes & Ideas · Tech Stack

Business modules default to `private`; operational modules like playbooks are often
`scoped` to specific internal agents. Set visibility per
[SPEC.md §6](../../../SPEC.md#6-security--the-permission-model). Add modules only when a
real workflow needs one.
