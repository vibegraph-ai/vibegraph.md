# Modules — Knowledge Base

Each file here is a **module**: a self-defined domain of your life you want AI tools to
be able to consult. `goals.md` is an example to copy or delete.

**Suggested personal modules:** Health & Wellness · Relationships · Finances · Career ·
Notes & Ideas · Time Management · Skills · Tech Stack · Goals

Add modules **only when you have a real use for one.** An empty template you never fill
is worse than no module at all. A module can be a single `.md` file or a folder with an
`index.md` plus supporting files.

Every module is `private` by default. Change `visibility` per the spec
([SPEC.md §6](../../../SPEC.md#6-security--the-permission-model)) if you want an agent to
read it.
