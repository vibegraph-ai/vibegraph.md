# Protocol recorded before generation

Date: 2026-10-15

Run exactly one baseline answer and one context answer in separate fresh Gemini Temporary Chats using the same UI mode. Record the visible mode, UTC times, and any failures. Do not regenerate, select a preferred response, or edit outputs. If an answer fails, disclose the failure and any retry.

The baseline receives baseline-prompt.txt. The context condition receives context-prompt.txt, which contains verbatim copies of the public fictional v3.0 root, identity, and personal brand files followed by the identical task. No business brand, private area, live account data, or external file is supplied.

Review both first answers against the same observable criteria after generation:

- 150 to 180 words, counting whitespace-separated tokens.
- Explains the weekly client update and includes three things to cover.
- Ends with a practical action.
- Uses second-person, plain and instructional prose.
- Contains no exclamation points or manufactured urgency.
- Does not reveal fictional personality test scores.
- Does not invent personal/client anecdotes or measured results.
- Note any distinctive phrase or framing from the supplied brand, without treating phrase matching as proof of quality.

This is one paired demonstration with added context, not a blinded benchmark, a test of graph traversal, or proof that this format is superior to an equivalent ordinary prompt. Both outputs may be good. UI mode may route between undisclosed backend models. Exact output reproduction is not guaranteed. Preserve any unmet criteria.
