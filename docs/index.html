The Vibegraph™

Your Vibes, Codified.

Every AI tool starts from zero — it doesn't know your voice, your values, or your taste, so it guesses toward the average. A vibegraph fixes the input. It's a small set of Markdown files that codifies who you are, so any AI tool, agent, or memory layer can sound like you. Like AGENTS.md, but for a person.

Build one → Read the spec on GitHub
The idea

Fix the input, not the output.

Ask ten people in the same field to have AI write a post on the same topic, and the results are nearly interchangeable — because the model draws on the same averaged prior for all ten. Editing that output forever is treating the symptom. A vibegraph treats the cause: it hands the AI a deliberate, structured statement of who you are, so the first draft already sounds like you.

It works the moment you paste it in. No platform has to adopt anything. That's the whole design.

Core Identity

Who you are

Small, stable, safe to share. The part you paste into any chat.

  • Personality (Big Five)
  • Purpose & meaning (Ikigai)
  • Brand positioning & voice
  • Visual aesthetics
Knowledge Base

What you know

Self-defined modules. Gated & permissioned. Grows over time.

  • Goals, health, finances…
  • Skills & playbooks
  • Anything you choose
  • Private by default
The shape

A folder of Markdown you own.

At its simplest, a vibegraph is a handful of files you can read, edit, and paste anywhere. There's a manifest an AI reads first, a Core, and as many modules as you want.

# you.vibegraph/
VIBEGRAPH.md          # the manifest an AI reads first
core/                 # Core Identity — who you are
  personality.md
  purpose.md
  brand-positioning.md
  brand-aesthetics.md
modules/              # Knowledge Base — what you know
  goals.md
  ...                 # private by default

Every item carries its own visibility: private, scoped, or public. Nothing is shared by omission. Businesses get the same structure with the instruments swapped — brand archetype and Aaker dimensions instead of a personality test, the Golden Circle instead of Ikigai.

Quickstart

Build one in an afternoon.

Copy a template

Grab templates/personal/ (or business/) into a folder named you.vibegraph.

Fill in the Core

Start with personality.md and work down. A rough Core beats an empty one.

Use it

Paste the manifest and the four Core files into any AI chat, or attach them to a Claude Project or custom GPT. Ask it to write in your voice.

Grow it

Add modules for the domains you actually want an agent to know — only when you have a real use.
